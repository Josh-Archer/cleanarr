# v0.2.57

## Release note

- Sends a high-priority ntfy alert when `MediaCleanup` fails to initialize
  against downstream media services.
- Raises `RuntimeError` during synchronous SQS record processing so Lambda
  reports `batchItemFailures` and SQS retries the webhook instead of dropping it.
- Documents `CLEANARR_NTFY_*` / `NTFY_*` configuration and the webhook error
  retry path.
