# v0.2.56

## Release note

- Adds generic webhook path-prefix exclusions that acknowledge protected media
  without queueing or processing cleanup events.
- Aligns Jellyfin webhook completion events with `ItemMarkPlayed` and
  `PlaybackStopped`; routine `UserDataSaved` notifications are no longer
  treated as completed playback.
- Includes the Jellyfin item path in the normalized webhook metadata so
  deployments can keep protected paths out of both proxy and consumer flows.
