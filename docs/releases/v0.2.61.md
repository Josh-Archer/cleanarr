# v0.2.61

Finished episode webhooks now use the same household watch map as the
scheduled scan. The webhook reads every Plex account, keeps the account that
sent the event watched, and sets `is_watched_override` false so
`require_all_users` still applies. Webhook log records stay on the loguru
logger and are copied to Loki, so Lambda still writes them to CloudWatch.

Architecture and security review: deletion still goes through
`should_delete_media` and the household policy. Play, pause, and stop events
do not delete. No new credentials or deployment endpoints are added. The
public safety scan, unit tests, and image builds run in the release workflow
before the images are published.
