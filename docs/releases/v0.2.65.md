# v0.2.65

Dry-run mode now writes per-user report artifacts from webhook and SQS runs,
so proposed cleanups can be reviewed before anything is deleted.

Transmission cleanup gains a Readarr path: torrents that Readarr reports as
imported and verified are eligible for removal, matching the existing
Sonarr and Radarr behavior. Webhook secret redaction is now covered for
mixed-case query parameters, extending the v0.2.64 redaction work.

The home GitOps deployment should pin these images by release tag and
immutable digest.
