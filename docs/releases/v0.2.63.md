# v0.2.63

Jellyfin webhook handling now accepts the plugin's `PlaybackStop` event and
requires its explicit `PlayedToCompletion` flag before starting finished-media
cleanup. Webhook cleanup decisions and Sonarr/Radarr outcomes are logged with
correlation IDs, without logging raw Jellyfin payloads or user/media data.

The home GitOps deployment must send the completion flag and pin this release's
webhook image digest. Mid-play stops remain non-finished events.
