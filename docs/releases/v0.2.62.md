# v0.2.62

Webhook log lines now include the event name and flags instead of a literal
`%s` template. Loki push failures record one warning with the HTTP status.
A 403 or 502 no longer prints a traceback, and Cloudflare Access headers are
attached to every Loki session, including a session created after the previous
one is closed.

Architecture and security review: deletion behavior is unchanged. The logging
change does not add credentials, endpoints, or request-body logging. Public
safety scan, unit tests, and image builds run in the release workflow before
the images are published.
