# v0.2.69

- Jellyfin 12.4: API calls send `Authorization: MediaBrowser Token="..."`
  instead of the removed legacy token header.
- Sonarr series matching for Jellyfin events now also matches by series
  folder path, so renamed or stylized folders (for example `PLUR1BUS`) resolve.
- Jellyfin/Emby deletes stay opt-in via `CLEANARR_JELLYFIN_DELETIONS` (default off).
