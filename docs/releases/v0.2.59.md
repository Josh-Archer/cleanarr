# v0.2.59

Matches imported stale torrents by Arr download ID (Transmission hash) as well
as exact release title. Imports of season packs can record an episode title
instead of the torrent title; the identical download hash establishes ownership.
Ignored-download events do not qualify, including those with matching hashes.

Architecture and security review: the change remains in the shared cleanup
library and preserves generic configuration and image-based integration.
Only actual import events populate the hash cache. Age, completion, stopped
status and existing ownership filters remain required; API failure keeps the
torrent. Removal remains metadata-only with `delete_data=False`. No credentials
or deployment-specific settings were added. Public safety scan, unit tests and
CI image builds must pass before the exact release gates are advanced.
