# v0.2.68

- Jellyfin/Emby finished events now use the Plex-user tag rules. Each
  Jellyfin user is mapped to a Plex user, either by exact case-insensitive
  name or through `CLEANARR_JELLYFIN_PLEX_USER_MAP_JSON` (`{"jfuser": "PlexUser"}`)
  or `CLEANARR_USER_ALIASES_JSON` entries that have both `plex` and `jellyfin` keys.
- The household is only the Sonarr/Radarr user tags. Untagged items never
  delete, and untagged or hidden accounts can't block a delete.
- `safe` / `kids` tags still block deletion before any user rule runs.
