# v0.2.60

Adds an opt-in Sonarr executable-only download cleanup path. It reads Sonarr's
completed-download warning queue, then requires the exact Transmission hash,
the `sonarr` label and category, and exactly one fully downloaded `.exe` file
at Sonarr's reported path. It sends Sonarr's queue delete request with
`removeFromClient=true`, `blocklist=true`, and `skipRedownload=true` so the
payload and matching release are removed together. Other warning types,
multi-file torrents, incomplete downloads, and non-Sonarr torrents are left
untouched. The feature honors `CLEANARR_DRY_RUN` and is disabled by default.

Architecture and security review: the shared library owns the reusable rule;
deployment-specific activation stays in `home`. Exact hash and payload checks
prevent title-only deletion, and the Sonarr API owns its blocklist operation.
The queue must be complete before any action. No secrets or home-specific
endpoints are added to the public package.
